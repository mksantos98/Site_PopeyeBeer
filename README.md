# ⚓ Popeye Beer 

> Onde o sabor encontra a tradição. Uma landing page moderna para uma experiência rústica.

O **Popeye Beer** é um site institucional desenvolvido para o setor de gastronomia e entretenimento (Pubs/Cervejarias). O foco do projeto foi criar uma interface que transmita a atmosfera de um pub real, utilizando tipografias marcantes e um layout otimizado para conversão.

---

## 🔗 Link de Acesso

Aproveite a experiência completa aqui: [https://mksantos98.github.io/Site_PopeyeBeer/](https://mksantos98.github.io/Site_PopeyeBeer/)

## 🔥 Funcionalidades Principais

* **Cardápio Digital:** Exposição organizada de bebidas e petiscos.
* **Design Dark Mode:** Paleta de cores otimizada para o ambiente noturno de pubs.
* **Totalmente Responsivo:** Navegação fluida em smartphones (ideal para clientes consultarem no local).

## 🛠️ Tecnologias e Conceitos

Para este projeto, foquei em performance e design limpo:

* **HTML5:** Estrutura semântica focada em SEO.
* **CSS3 (Custom Properties):** Uso de variáveis para manter a consistência das cores e fontes.
* **Flexbox & Grid:** Para um layout que se adapta perfeitamente a qualquer tela.
* **JavaScript:** Interações de menu e efeitos de scroll.

## 📦 Estrutura do Repositório

* `index.html`: Página principal e única (SPA Style).
* `css/`: Folhas de estilo organizadas por componentes.
* `img/`: Ativos visuais de alta qualidade (cervejas, pratos, logo).
* `js/`: Scripts de animação e interatividade.
